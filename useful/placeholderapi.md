# PlaceholderAPI

| Placeholder                               | Description                               |
| ----------------------------------------- | ----------------------------------------- |
| `%xbattlepass_category_<id>_duration%`    | The time until the category ends/locks.   |
| `%xbattlepass_category_<id>_reset_timer%` | The time until the category resets.       |
| `%xbattlepass_category_<id>_start_date%`  | The start date of the quest category.     |
| `%xbattlepass_claimable_<battlepass>%`    | The amount of claimable tiers/rewards.    |
| `%xbattlepass_tier_<battlepass>%`         | The player's current Battlepass tier.     |
| `%xbattlepass_xp_<battlepass>%`           | The player's current tier xp.             |
| `%xbattlepass_xp_required_<battlepass>%`  | The amount of xp needed until tiering up. |
