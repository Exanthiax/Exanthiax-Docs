# PlaceholderAPI

| Placeholder                                        | Description                                                  |
| -------------------------------------------------- | ------------------------------------------------------------ |
| `%xbattlepass_category_<id>_start_date%`           | The start date of the quest category.                        |
| `%xbattlepass_category_<id>_end_date%`             | The end date of the quest category.                          |
| `%xbattlepass_category_<id>_start_timer%`          | the time until the category starts.                          |
| `%xbattlepass_category_<id>_end_timer%`            | The time until the category ends.                            |
| `%xbattlepass_category_<id>_reset_timer%`          | The time until the category resets.                          |
| `%xbattlepass_claimable_<battlepass>%`             | The amount of claimable tiers/rewards.                       |
| `%xbattlepass_tier_<battlepass>%`                  | The player's current Battlepass tier.                        |
| `%xbattlepass_tier_<battlepass>_numeral%`          | The player's current Battlepass tier in numerals.            |
| `%xbattlepass_xp_<battlepass>%`                    | The player's current tier xp.                                |
| `%xbattlepass_xp_<battlepass>_formatted%`          | The player's current tier xp, formatted with commas.         |
| `%xbattlepass_xp_required_<battlepass>%`           | The amount of xp needed for the tier.                        |
| `%xbattlepass_xp_required_<battlepass>_formatted%` | The amount of xp needed for the tier, formatted with commas. |
