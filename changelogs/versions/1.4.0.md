# 📋 1.4.0

## 🔼 Upstream libreforge Update

> This update includes major improvements and new integrations from the core l**ibreforge** library. These features and fixes will enhance your plugin's effect, trigger, and integration capabilities.

***

## 🧱 Technical
- Removed support for **Minecraft 1.17 – 1.21.3**  
  Only **1.21.4+** is now supported
- Various codebase cleanups and refactors to utilize **modern server APIs**

---

## 🐛 Fixes
- Fixed **custom biome support**
- Fixed **potion_duration_multiplier**
- Fixed `refresh.cooldown` not working in `libreforge/config.yml`
