# 📋 1.3.0

## 🔼 Upstream libreforge Update

> This update includes major improvements and new integrations from the core l**ibreforge** library. These features and fixes will enhance your plugin's effect, trigger, and integration capabilities.\
> &#xNAN;_(Thanks to contributors: ChimpGamer, Miryex, OfTeN, & PQguanfang)_

***

### 🎯 Effects System

* Added `give_mobcoins` and `take_mobcoins` effects
* Improved `create_explosion` effect
* Improved `(permanent_)potion_effect` effects
* Improved `edprison_economy_multiplier` effect
* Added `cast_mythic_skill` effect
* Fixed `knockback_resistance_multiplier` and `explosion_knockback_resistance_multiplier` (Thanks **Exanthiax**)

### 🎯 Triggers & Filters

* Added Purpur triggers:
  * `anvil_modify`
  * `grind_item`
* Added new triggers:
  * `compost_item`
  * `collide_with_entity`
  * `tamed_entity`
  * `is_tamed_owner`
* Improved `player_trade` trigger

### 🐛 Fixes

* Fixed `take_damage` dispatching on invulnerable players
* Fixed error with `catch_fish` when using CustomFishing
* Fixed `below_balance` condition

### 🎯 Integrations

* `telekinesis`, `damage_multiplier`, `take_damage`, and `take_entity_damage` now support **MythicMobs**
* Telekinesis now supports drops from **tamed mob kills**
* Added experimental `villager_trade_multiplier` effect

### 🧭 Command Changes

* Added wildcard `*` values to `player` argument in `/libreforge points` commands
* Added `/libreforge reset` command
