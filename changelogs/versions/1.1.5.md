# 📋 1.1.5

### 🖼️ GUI Changes

* Added new `gui-title` option to `<category>.yml`\
  Allows setting a **separate GUI title** from the category's **button name**
  * You will need to update your configs if your Category buttons look unformatted.
* Updated default files to include `gui-title`
* Updated default page buttons in battlepass GUI for improved consistency

***

### 💬 Internal Placeholders

* Added new `%tier_x%` placeholder\
  `x` is an offset from the current tier level\
  &#x20;   _Example: if `%level%` = `5`, then `%tier_1%` = `6`, `%tier_-1%` = `4`_
* Added a list of available internal placeholders to `config.yml` for easier reference
