# 📋 1.5.0

### 🎯 Effects System

* Fixed `battlepass_xp_multiplier` effect not working
* Fixed effect system error logging messages

### 🖼️ GUI Changes

* Added new sound for when a player unlocks a premium battle pass
* Added new sound for when a player clicks a locked or in-progress slot
* Fixed issue where reward-claim messages/sounds would not run if a reward had no effects defined.\
  **New behavior:** If a reward is defined in the battlepass config, it will send claim messages and sounds when claimed.

### 🗨️ Lang Changes

* Added new entry for attempting to claim a premium reward without the premium pass
* Added new entries for the new `setpremium` command

### 🧭 Command Changes

* Added new `/xbattlepass setpremium` command\
  **Usage:** `/xbattlepass setpremium <player> <pass_id> <true/false> [silent]`
* Added `/xbattlepass complete_task` command\
  **Usage:** `/xbattlepass complete_task <player/all> <pass_id> <category_id> <quest_id> <task_id>`
* Added `task_xp` support to `/xbattlepass give`\
  **Usage:** `/xbattlepass give <player/all> task_xp <category_id> <quest_id> <task_id> <amount>`
* Added task support to `/xbattlepass reset` command\
  **Usage:** `/xbattlepass reset task <player/all> <pass_id> <category_id> <quest_id> <task_id>`

### 🧰 API Changes

* Added `setPremium` method to API
