# 1.1.0

* Added `custom-slots` to all GUI sections in config.yml
* Added `_numeral` placeholders, e.g. `%xbattlepass_tier_battlepass_numeral%`
* Added `date-format` option to config.yml
* Added `%battlepass_<category>_start_timer%` placeholder
* Added `category-in-progress` message into lang.yml
* Added `%xbattlepass_<category>_end_date%` placeholder
* Changed `%xbattlepass_<category>_duration%` to `%xbattlepass_<category_id>_end_timer%` in line with new placeholders
* Added `category-expired` message to lang.yml
* Fixed `%xbattlepass_<category>_reset_timer%` now shows time until reset
* Fixed `has_bp_premium` and `has_battlepass_tier` conditions inconsistently working
* Fixed error messages on both conditions
* Fixed internal placeholders not working in `/battlepass` GUI
* Added `%pass%`, `%next_tier%` and `%next_tier_numeral%` internal placeholders
* Fixed tab-complete for commands
* Added `xp/tiers` arg to `/xbattlepass give` command
* Added `all` within player args for `/xbattlepass give` and `/xbattlepass reset`
* Added `giveExactBPTiers` to API
* Removed redundant lang.yml lines
  * give-xp
  * give-levls
  * admin-give-xp
  * admin-give-levels
* Added new lang.yml lines
  * type-required
  * invalid-type
  * given-experience
  * given-tiers
  * received-experience
  * received-tiers
* Changed default internal placeholders (requires changes)
  * `%current_xp%` -> `%current_bp_xp%`
  * `%required_xp%` -> `%required_bp_xp%`
  * `%current%` -> `%current_task_xp%`
  * `%required%` -> `%required_task_xp%`
  * Updated all default config files
* Added new formatted (commas) internal placeholders
  * `%current_bp_xp_formatted%`&#x20;
  * `%required_bp_xp_formatted%`
  * `%current_task_xp_formatted%`
  * `%required_task_xp_formatted%`&#x20;
* Added `%claimable_tiers%` internal placeholder
* Fixed external placeholders not displaying in GUIs (Thanks Auxilor!)
