# 1.0.2

* Fixed incorrect timers being displayed on quests
* Fixed blank lines not working in some lore items
* Fixed config.yml to look better for default configs
* Fixed default category configs having incorrect reset durations
* Setting task-amount to a value less than the number of tasks available will select tasks at random
* Added %time% placeholder and time-format to category configs
* Updated all default configs to reflect changes
