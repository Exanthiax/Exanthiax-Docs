# 📋 1.0.2

### 🐛 Fixes

* Fixed incorrect timers being displayed on quests
* Fixed blank lines not working in some lore items
* Fixed `config.yml` formatting for improved readability in default configs
* Fixed default category configs having incorrect reset durations

### ⚙️ Other Changes

* Setting `task-amount` to a value less than the number of available tasks will now select tasks **at random**
* Added `%time%` placeholder and `time-format` option to category configs
* Updated all default config files to reflect recent changes
